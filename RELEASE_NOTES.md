# v0.4.15 - hardware prototype prerelease

Firmware 0.4.15 with Portfolio client 0.4.14. Preserves the working English SKYNET terminal, configurable card settings, camera and voice modes, fast radio controls, streamed TTS and radio pause/resume. Adds the tested automatic speech/music level matching from the latest firmware.

Defaults: voice on, robot effect on, speaker volume 40. Radio: five synthwave/vaporwave stations. The client retains the blank row between startup controls and OPERATOR>.

Includes source, build instructions, a placeholder setup file and portable tests. Private credentials and personal logs are excluded. Enclosure files are maintained separately.

This is a prerelease for the tested hardware assembly; see docs/KNOWN_LIMITATIONS.md.
